# Developing Finance KPI Dashboard

## Problem Statement

A manufacturing company wants to monitor its overall financial performance using an interactive Power BI dashboard. Senior management requires a single dashboard to analyze budget allocation, actual expenditure, budget variance, budget utilization, department performance, category-wise spending, regional performance, and payment methods. The objective is to design an interactive **Finance KPI Dashboard** using the **Budget vs Actual Financial Dataset** that supports effective financial monitoring and business decision-making.

**Dataset Used:** Budget vs Actual Financial Dataset (Kaggle)
## Dataset

The project uses the **Budget vs Actual Financial Dataset** provided in the assignment.

**Dataset Source:** Kaggle

**Dataset Link:**
[https://www.kaggle.com/datasets/kennathalexanderroy/budget-vs-actual-financial-dataset](https://www.kaggle.com/datasets/kennathalexanderroy/budget-vs-actual-financial-dataset)

### Dataset Columns

* Date
* Department
* Category
* Region
* Budget Amount
* Actual Amount
* Payment Method
* Transaction ID
  
## Methodology / Steps Followed

1. Downloaded the Budget vs Actual Financial Dataset from Kaggle.
2. Imported the dataset into Power BI Desktop using the **Get Data** option.
3. Opened Power Query Editor and verified the data types of all columns.
4. Checked the dataset for duplicate records and missing values.
5. Converted the Date column into Date format for time-based analysis.
6. Verified Budget Amount and Actual Amount as numeric fields.
7. Checked categorical fields such as Department, Category, Region, and Payment Method.
8. Verified Transaction ID values for transaction analysis.
9. Loaded the cleaned dataset into Power BI Desktop.
10. Created financial KPI measures for dashboard analysis.
11. Created KPI Cards to display total budget, total actual expenditure, budget variance, budget utilization, and total transactions.
12. Created a Clustered Column Chart to compare total budget and total actual expenditure by department.
13. Created a Donut Chart to analyze actual expenditure by payment method.
14. Created a Bar Chart to analyze budget variance by department.
15. Created charts to analyze actual expenditure by region.
16. Created a Year-wise chart to compare total budget and total actual expenditure.
17. Created a Treemap to analyze budget amount by category.
18. Created a financial summary table for department-wise analysis.
19. Added interactive slicers for Year, Department, Region, Category, and Payment Method.
20. Applied professional formatting and a dark corporate finance theme to the dashboard.

8. Which region has the highest actual expenditure?
9. Which payment method has the highest actual transaction value?
10. How does financial performance change across different years?

## Results

* The Budget vs Actual Financial Dataset was successfully imported and analyzed using Power BI.
* Data quality was checked by verifying data types, duplicate records, missing values, and transaction information.
* KPI cards provided an overview of total budget, actual expenditure, budget variance, budget utilization, and total transactions.
* Department-wise charts helped compare budget allocation with actual expenditure.
* Budget variance analysis helped identify departments with higher or lower financial variance.
* Category analysis provided an overview of budget allocation across different financial categories.
* Region-wise analysis helped compare actual expenditure across different regions.
* Payment method analysis showed the distribution of actual expenditure across different payment methods.
* Year-wise analysis helped compare financial performance over time.
* Interactive slicers allowed users to filter the dashboard according to their requirements.
* The dashboard showed approximately **795M Total Budget** and **890M Total Actual Amount**.
* Overall budget utilization was approximately **112%**, indicating that actual expenditure was higher than the allocated budget.
* The dashboard provided a clear and interactive view of financial performance for management decision-making.
